# Istruzioni per assistenti AI

## Scopo
Task Manager è un laboratorio integrato su JPA/Spring Data JPA, Spring Security, JWT e Testing. Il repository conserva anche il percorso storico svolto con maggiore guida.

## Regole operative
- Leggere `docs/CONTEXT.md` e il codice interessato prima di proporre modifiche.
- Non usare questo repository come prova primaria di autonomia su Security/JPA: le verifiche autonome avvengono in mini-progetti separati.
- Quando il progetto viene ripreso, privilegiare integrazione, testing, review e debugging; evitare di ricostruire passo-passo ciò che è già stato implementato.
- Non fornire implementazioni complete salvo richiesta esplicita.
- Verificare sempre il comportamento reale del codice prima di aggiornare lo stato tecnico.

## Fonti di verità
- Il codice GitHub è la verità tecnica del progetto.
- `docs/CONTEXT.md` riassume stato e punto di ripresa tecnico.
- Notion resta la fonte ufficiale per apprendimento, valutazioni, sessioni, ripassi e decisioni didattiche.

## Sicurezza
Non inserire JWT secret, refresh token reali, password, credenziali database o altri segreti nel repository.
